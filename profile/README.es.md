## 👋 Quiénes somos

Un equipo de desarrolladores franceses centrado en servidores de juego
y el ecosistema Discord.

Creamos las herramientas que nosotros mismos usamos:
limpias, probadas, documentadas y pensadas para el rendimiento.

Nada de código desechable. Si no está listo, no se publica.

---

## 🧩 Qué construimos

### ⚙️ [`@aegis/core`](https://github.com/aegis0x/core)
La base común de nuestros recursos.
Una base estable, modular y ligera sobre la que se apoya todo lo demás.

### 🛡️ [`@aegis/shield`](https://github.com/aegis0x/shield)
Seguridad y protección anticheat.
Detección, registros y blindaje para mantener tu servidor limpio.

### 🤖 [`@aegis/mcp`](https://github.com/aegis0x/mcp)
El puente entre tu servidor y los agentes de IA.
Controla, supervisa y automatiza mediante el Model Context Protocol.

## ⚡ Nuestro enfoque

- **Calidad verificada**: cada recurso se prueba y optimiza antes de salir.
- **Entrega instantánea**: pagas, descargas, despliegas.
- **Actualizaciones de por vida**: comprado una vez, mejorado para siempre.
- **Soporte ágil**: desarrolladores de verdad que responden, en varios idiomas.
